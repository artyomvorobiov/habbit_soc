# Streakmates — трекер привычек, которыми хочется хвастаться

Минималистичный трекер привычек для iPhone (и сразу для Android — код общий), где друзья видят
прогресс друг друга, поддерживают реакциями и соревнуются в челленджах.

> «Streakmates» — рабочее название. Как переименовать, написано [ниже](#как-переименовать-приложение).

## Что умеет приложение

**Привычки**
- Привычка = название, эмодзи, цвет и расписание (каждый день, будни или свои дни недели).
- Экран «Сегодня»: полоса из последних 7 дней с кольцами прогресса, общий прогресс дня,
  отметка привычки одним нажатием (с вибрацией).
- Серии 🔥: текущая и лучшая. Пропуск дня *вне* расписания серию не рвёт, а отметка в
  выходной добавляется как бонус.
- Экран привычки: календарь по месяцам (можно отметить прошлые дни), процент выполнения
  за 30 дней, общее число отметок, архив и удаление.
- Напоминания в выбранное время. Если привычка на сегодня уже отмечена, напоминание не придёт.

**Социальное (ради виральности)**
- Приватность у каждой привычки: «Друзья» или «Только я». Правило действует на уровне базы
  данных, поэтому чужие приватные привычки нельзя получить даже в обход приложения.
- Друзья: поиск по никнейму, заявки, ссылка-приглашение `streakmates://u/<ник>`.
- Лента друзей: свежие отметки друзей, реакции 🔥 👏 💪 ❤️ 🎉, отметка «Рекорд!» на сериях
  3, 7, 14, 21, 30, 50, 100… дней.
- Профиль друга: его открытые привычки, серии, тепловая карта активности, кнопка «Вызвать».
- **Карточка для сторис**: красивая картинка «🧘 Медитация — 45 дней подряд» с картой
  активности и вашим ником. Её можно отправить в Instagram, Telegram и куда угодно.
  Каждая такая публикация — реклама приложения.

**Челленджи (соревнования в одной привычке)**
- Название, эмодзи, срок (7/14/21/30 дней), старт сегодня, завтра или с понедельника.
- Приглашения друзьям и 8-значный код/ссылка для всех остальных — удобно для чатов.
- Таблица лидеров с медалями 🥇🥈🥉, прогресс-барами и отметкой «сегодня выполнено».
- Челлендж автоматически появляется в списке «Сегодня» у каждого участника. Дни до
  вступления не засчитываются, так что задним числом накрутить очки нельзя.
- После финиша — победитель, а привычка остаётся в списке, чтобы продолжать серию.

**Фото и общение (версия 1.1)**
- **Фото-подтверждения**: к отметке можно приложить фото и пару слов («5 км, рассвет 🌅»).
  Друзья видят фото в ленте, у каждой привычки появляется фотодневник. Фото хранятся
  в закрытом хранилище, и видят их только те, кому видна сама отметка.
- **Чат в каждом челлендже**: сообщения и фото. Отметки участников появляются в чате
  сами («✅ День 3 выполнен» с фото-пруфом). Сверху висит напоминание «Вы ещё не отметились
  сегодня» с кнопкой «📸 С фото». На вкладке есть счётчик непрочитанного.
- **Челленджи «только с фото»**: при создании можно включить режим, в котором засчитываются
  только отметки с фото-подтверждением. Накрутить очки без пруфа не получится.
- **Уведомления**: колокольчик на вкладке «Друзья» собирает реакции на ваши отметки, заявки
  в друзья, приглашения в челленджи и «пинки».
- **«Пнуть» 👉**: напомнить другу или сопернику по челленджу, что пора отметиться.
  Пнуть одного человека можно не чаще раза в день.
- **Push-уведомления** о реакциях, заявках, приглашениях, пинках и сообщениях в чатах,
  каждое на языке телефона получателя (настройка — в разделе
  [«Push-уведомления»](#push-уведомления)).
- **Итоги недели**: карточка для сторис с процентом выполнения, числом отметок, лучшей
  серией, «идеальными днями» и точками по каждой привычке (Профиль → Итоги недели).

**Остальное**
- Регистрация по email и паролю, восстановление пароля кодом из письма.
- Русский и английский языки (выбирается по языку телефона), светлая и тёмная тема.
- Удаление аккаунта, блокировка пользователей и жалобы. Всё это обязательно для App Store.

## Как это устроено

| Часть | Технология | Зачем |
|---|---|---|
| Приложение | [Expo](https://expo.dev) (React Native + TypeScript), SDK 57 | Один код для iPhone и Android. Можно запускать на iPhone без Mac |
| Навигация | Expo Router + нативная панель вкладок iOS | Выглядит как родное iOS-приложение |
| Сервер и база | [Supabase](https://supabase.com) (Postgres, Storage, Realtime) | Готовые аккаунты, база, хранилище фото и живые обновления чата. Есть бесплатный тариф |
| Сборка и публикация | EAS Build / EAS Submit | Собирает iOS-приложение в облаке, Mac не нужен |

```
src/app/            экраны (каждый файл = экран)
  sign-in.tsx         вход и регистрация
  onboarding.tsx      выбор имени, ника и аватара
  (app)/(tabs)/       четыре вкладки: Сегодня, Друзья, Челленджи, Профиль
  (app)/habit/...     создание, просмотр, редактирование, карточка для сторис
  (app)/proof/...     фото-подтверждение отметки
  (app)/challenge/... создание и страница челленджа
  (app)/chat/[id].tsx чат челленджа
  (app)/activity.tsx  уведомления
  (app)/recap.tsx     итоги недели
  (app)/friends.tsx, user/[id].tsx, settings.tsx, ...
src/components/     элементы интерфейса
src/lib/            логика: запросы к Supabase, серии, даты, тексты (i18n.ts), уведомления
supabase/schema.sql вся база данных: таблицы, правила доступа, серверные функции
supabase/tests/     автотесты базы данных
assets/images/      иконка и заставка
```

## Обновление до версии 1.1 (фото, чаты, уведомления)

Если первую версию вы уже запускали:

1. Скачайте новый код: `git pull`, или скачайте ZIP заново и перенесите в него свой файл `.env`.
2. Установите новые библиотеки:
   ```bash
   npm install
   ```
3. Обновите базу: Supabase → **SQL Editor** → **New query** → вставьте **всё** содержимое
   [`supabase/schema.sql`](supabase/schema.sql) → **Run**. Скрипт сам добавит новые таблицы,
   хранилище фото `photos` и правила доступа. Ваши привычки, друзья и отметки сохранятся.
4. Запустите приложение с очисткой кеша:
   ```bash
   npx expo start -c
   ```

Push-уведомления включаются отдельно, см. [ниже](#push-уведомления). Всё остальное
(фото, чаты, уведомления внутри приложения, «пинки», итоги недели) работает сразу,
в том числе в Expo Go.

## Пошаговая инструкция

### Шаг 0. Что понадобится

- Компьютер на Windows, macOS или Linux. **Mac не обязателен.**
- [Node.js](https://nodejs.org) версии LTS (22 или новее). Установите и проверьте в терминале
  командой `node -v`.
- [Git](https://git-scm.com), чтобы скачать код (можно и просто скачать ZIP с GitHub).
- iPhone с приложением **Expo Go** из App Store — для тестирования.
- Бесплатный аккаунт на [supabase.com](https://supabase.com).
- Для публикации в App Store позже понадобятся бесплатный аккаунт на [expo.dev](https://expo.dev)
  и [Apple Developer Program](https://developer.apple.com/programs/) ($99 в год).

### Шаг 1. Создайте базу данных в Supabase (≈10 минут)

1. Зайдите на [supabase.com](https://supabase.com), нажмите **New project**. Придумайте
   название и пароль базы, регион выберите поближе к пользователям (например, Frankfurt).
2. Когда проект создастся, откройте слева **SQL Editor**, нажмите **New query**, скопируйте
   **всё** содержимое файла [`supabase/schema.sql`](supabase/schema.sql), вставьте и нажмите
   **Run**. Должно появиться «Success. No rows returned».
   > Файл можно запускать повторно (например, после обновления кода): данные не удалятся.
3. Выключите подтверждение email на время тестов: **Authentication → Sign In / Providers →
   Email** → выключите **Confirm email** → Save. Иначе после регистрации придётся
   подтверждать почту по ссылке из письма. Для настоящего запуска см.
   [«Письма и восстановление пароля»](#письма-и-восстановление-пароля).
4. Возьмите ключи подключения: кнопка **Connect** вверху страницы проекта (или
   **Project Settings → API Keys** и **Data API**). Понадобятся:
   - **Project URL**, вида `https://abcdefgh.supabase.co`;
   - **anon / publishable key**, длинная строка. Этот ключ публичный, его можно хранить
     в приложении. Ключ `service_role` / `secret` в приложение **никогда** не вставляйте.

### Шаг 2. Скачайте и настройте проект (≈5 минут)

```bash
git clone https://github.com/artyomvorobiov/habbit_soc.git
cd habbit_soc
npm install
```

Создайте в папке проекта файл `.env` (скопируйте `.env.example`) и впишите свои значения:

```
EXPO_PUBLIC_SUPABASE_URL=https://abcdefgh.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### Шаг 3. Запустите на своём iPhone (≈2 минуты)

1. Установите на iPhone **Expo Go** из App Store.
2. На компьютере в папке проекта выполните:
   ```bash
   npx expo start
   ```
3. Наведите камеру iPhone на QR-код в терминале, и приложение откроется в Expo Go.
   Компьютер и телефон должны быть в одной Wi-Fi сети. Если не получается, запустите
   `npx expo start --tunnel`.
4. Зарегистрируйтесь, создайте привычку и отметьте её 🎉

Чтобы проверить социальные функции, зарегистрируйте второй аккаунт (например, на телефоне
друга через тот же QR-код или в браузере: нажмите `w` в терминале), добавьте друг друга
по нику и создайте челлендж.

> Код можно менять прямо во время работы: приложение на телефоне обновится само.
> Если после изменения `.env` ничего не поменялось, перезапустите с очисткой кеша: `npx expo start -c`.

### Шаг 4. Раздайте приложение друзьям через TestFlight

Expo Go подходит для разработки, а друзьям лучше ставить «настоящее» приложение через
TestFlight (официальная бета-раздача Apple).

1. Оформите [Apple Developer Program](https://developer.apple.com/programs/enroll/)
   ($99/год, активация занимает от нескольких часов до пары дней).
2. В `app.json` замените `com.yourname.streakmates` (в `ios.bundleIdentifier` и
   `android.package`) на свой уникальный идентификатор, например `com.masha.streakmates`.
3. Установите инструменты сборки и привяжите проект к аккаунту expo.dev:
   ```bash
   npm install -g eas-cli
   eas login
   eas init
   ```
4. Передайте ключи Supabase облачной сборке. Файл `.env` в облако **не отправляется**,
   это сделано специально. Выполните:
   ```bash
   eas env:set --name EXPO_PUBLIC_SUPABASE_URL --value "https://abcdefgh.supabase.co" --environment production --environment preview --visibility plaintext
   eas env:set --name EXPO_PUBLIC_SUPABASE_ANON_KEY --value "eyJhbGciOi..." --environment production --environment preview --visibility plaintext
   ```
   Можно и без консоли: на [expo.dev](https://expo.dev) → ваш проект → **Environment
   variables** добавьте эти две переменные для окружений *production* и *preview*.
5. Соберите приложение в облаке:
   ```bash
   eas build --platform ios --profile production
   ```
   EAS попросит войти в Apple-аккаунт и сам создаст сертификаты. Сборка идёт 15–30 минут.
6. Отправьте сборку в App Store Connect:
   ```bash
   eas submit --platform ios --latest
   ```
7. В [App Store Connect](https://appstoreconnect.apple.com) → ваше приложение → **TestFlight**:
   - **Internal testing** — до 100 человек из вашей команды, без проверки Apple;
   - **External testing** — до 10 000 человек по публичной ссылке, после короткой бета-проверки Apple.

   Друзья ставят TestFlight из App Store и открывают вашу ссылку.

### Шаг 5. Публикация в App Store

Перед отправкой на проверку:

1. **Политика конфиденциальности (обязательно).** Опубликуйте страницу (подойдут Notion,
   Google Docs или GitHub Pages) и впишите её адрес и email поддержки в
   [`src/lib/config.ts`](src/lib/config.ts) (`PRIVACY_POLICY_URL`, `SUPPORT_EMAIL`).
2. **Письма**: настройте SMTP (см. следующий раздел) и снова включите **Confirm email**,
   если нужно подтверждение почты.
3. В App Store Connect заполните карточку: описание, ключевые слова, скриншоты
   (iPhone 6.9"), категорию **Health & Fitness** или **Lifestyle**, возрастной рейтинг.
4. **App Privacy**: укажите, что собираются *Email*, *User Content* (названия привычек,
   сообщения в чатах) и *Photos* (фото-подтверждения). Всё это привязано к пользователю
   и **не** используется для трекинга.
5. **Демо-аккаунт для ревьюера (обязательно!)**: создайте тестовый аккаунт с парой
   привычек и другом, а логин и пароль впишите в *App Review Information*. Без него
   приложение с регистрацией отклонят.
6. Требования Apple, которые уже выполнены в коде: удаление аккаунта (Настройки → Удалить
   аккаунт), блокировка и жалобы на пользователей (меню «⋯» в профиле друга). Жалобы
   попадают в таблицу `reports`. Просматривайте её в Supabase: **Table Editor → reports**.
7. Новая версия: поднимите `version` в `app.json`, затем снова `eas build` и `eas submit`.

### Письма и восстановление пароля

- Встроенная почта Supabase предназначена только для тестов: она отправляет очень мало писем
  в час. Для настоящих пользователей подключите свой SMTP (например,
  [Resend](https://resend.com), у него есть бесплатный тариф): **Authentication → Emails →
  SMTP Settings**.
- Чтобы работала кнопка «Забыли пароль?», письмо должно содержать **код**, а не ссылку.
  Откройте **Authentication → Emails → Reset Password** и замените текст, например, на:
  ```html
  <h2>Восстановление пароля</h2>
  <p>Ваш код: <strong>{{ .Token }}</strong></p>
  <p>Введите его в приложении Streakmates.</p>
  ```

### Push-уведомления

Уведомления внутри приложения (колокольчик) работают без настройки. Чтобы они ещё и
приходили на телефон, когда приложение закрыто:

1. **Включите pg_net в Supabase**: **Database → Extensions** → найдите `pg_net` → включите.
   Потом снова выполните `supabase/schema.sql`. Через это расширение база сама отправляет
   push через сервис Expo.
2. **Привяжите проект к Expo**, если ещё не делали этого для TestFlight:
   `npm install -g eas-cli`, затем `eas login` и `eas init`. Команда допишет в `app.json`
   идентификатор проекта: без него телефон не может получить адрес для push.
3. Проверяйте push в **сборке через TestFlight** (шаг 4 ниже). При первой сборке EAS
   предложит создать ключ Apple Push Notifications: соглашайтесь. В Expo Go и в симуляторе
   push может не работать, это нормально.

После этого телефон получит push, когда друг поставит реакцию, пришлёт заявку, позовёт
в челлендж, «пнёт» или напишет в чат.

### Android: Google Play и RuStore

Код уже кроссплатформенный, отдельно писать ничего не нужно. В `eas.json` есть три профиля:
`preview` (APK для установки на свой телефон), `production` (AAB для Google Play) и
`rustore` (APK для RuStore).

**1. Проверить на телефоне**
- Быстро: установите **Expo Go** из Google Play и отсканируйте QR-код из `npx expo start`.
- Как настоящее приложение: `npx eas-cli@latest build --platform android --profile preview`.
  В конце будет ссылка и QR-код: откройте её на телефоне, скачайте APK и установите
  (Android попросит разрешить установку из этого источника).

**2. Push-уведомления на Android (Firebase)**
Без этого шага всё работает, кроме push (напоминания приходят и так).
1. [console.firebase.google.com](https://console.firebase.google.com) → создайте проект →
   **Add app → Android**, package name `com.artem.streakmates` (как в `app.json`).
2. Скачайте `google-services.json`, положите в корень проекта и добавьте в `app.json` в раздел
   `android` строку `"googleServicesFile": "./google-services.json"`.
3. Firebase → ⚙️ **Project settings → Service accounts → Generate new private key**: скачается
   JSON-ключ. **Не кладите его в проект.**
4. `npx eas-cli@latest credentials` → Android → production → **Google Service Account →
   Manage your Google Service Account Key for Push Notifications (FCM V1)** → загрузите этот ключ.
5. Пересоберите приложение.

**3. Google Play**
1. Аккаунт [Google Play Console](https://play.google.com/console): разовый взнос $25
   (карта должна быть иностранной), проверка личности.
2. **Для новых личных аккаунтов** Google требует закрытое тестирование: не меньше
   **12 тестировщиков** в течение **14 дней подряд**. Только после этого можно запросить
   публикацию для всех. Соберите друзей заранее.
3. В консоли: **Create app**, затем заполните *App content*: ссылка на политику
   конфиденциальности, **Data safety** (email, имя, фото, сообщения; данные шифруются при
   передаче; пользователь может удалить аккаунт), **ссылка на удаление аккаунта** (подойдёт
   опубликованная политика: в разделе 7 написано, как удалить аккаунт), возрастной рейтинг,
   целевая аудитория (13+), реклама: нет.
4. Сборка: `npx eas-cli@latest build --platform android --profile production` (файл `.aab`).
5. **Первый раз загрузите `.aab` вручную**: скачайте его со страницы сборки на expo.dev,
   затем Play Console → *Testing → Internal testing* (или *Closed testing*) → *Create new release*.
6. Дальше можно отправлять из консоли: создайте в Google Cloud сервисный аккаунт с доступом к
   Play Console ([инструкция Expo](https://github.com/expo/fyi/blob/main/creating-google-service-account.md))
   и запустите `npx eas-cli@latest submit --platform android --latest`. Сборка уйдёт черновиком
   во внутреннее тестирование. Когда приложение опубликуется, в `eas.json` можно поменять
   `track` на `production`, а `releaseStatus` на `completed`.

**4. RuStore**
1. [console.rustore.ru](https://console.rustore.ru): регистрация бесплатная, физлицо может
   публиковать бесплатные приложения (вход через VK ID, подтверждение через Госуслуги).
2. Сборка: `npx eas-cli@latest build --platform android --profile rustore` (файл `.apk`).
3. В консоли: *Создать приложение* → загрузите APK, иконку 512×512, скриншоты, описание,
   ссылку на политику конфиденциальности, возрастной рейтинг. Модерация обычно 1–5 рабочих дней.
4. Google Play переподписывает приложение своим ключом, поэтому версии из Google Play и
   RuStore подписаны по-разному. Кто установил из одного магазина, обновляется из него же.

## Как переименовать приложение

1. `app.json`: `name` (название под иконкой), `slug`, `scheme` (для ссылок), `bundleIdentifier`, `package`.
2. `src/lib/config.ts`: `APP_SCHEME` (должен совпадать со `scheme`).
3. `src/lib/i18n.ts`: `appName` в обоих языках.
4. Иконка и заставка: `assets/images/icon.png` (1024×1024, без прозрачности),
   `splash-icon.png` и `android-icon-*.png`.

Все тексты интерфейса лежат в `src/lib/i18n.ts`, цвета — в `src/lib/theme.ts`.

## Для разработчиков

```bash
npm run typecheck   # проверка типов
npm run lint        # линтер
npm test            # тесты логики серий и дат
npm run test:db     # тесты базы данных (нужен локальный Postgres, см. supabase/tests/run.sh)
```

- Все правила доступа (кто что видит, включая фото и чаты) описаны в `supabase/schema.sql`
  и покрыты тестами в `supabase/tests/test_schema.sql` и `supabase/tests/test_v2.sql`.
- Правила подсчёта серий есть в двух местах: `src/lib/streaks.ts` (приложение) и
  `habit_current_streak()` в `schema.sql` (лента и список друзей). Меняйте их вместе.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Экран «Подключите Supabase» | Нет файла `.env` или в нём ошибка. Исправьте и запустите `npx expo start -c` |
| В собранном через EAS приложении экран «Подключите Supabase» | Не заданы переменные окружения EAS (шаг 4, пункт 4) |
| После регистрации не пускает | Включено подтверждение email: подтвердите почту по ссылке или выключите Confirm email (шаг 1, пункт 3) |
| Expo Go пишет про несовместимую версию SDK | Обновите Expo Go в App Store |
| Телефон не видит компьютер | `npx expo start --tunnel` |
| Ошибки при запуске `schema.sql` | Запускайте файл целиком. Если ошибка повторяется, пришлите её текст |
| Фото не загружаются | Выполните `schema.sql` ещё раз: он создаёт хранилище `photos` и правила доступа к нему |
| Чат обновляется с задержкой | Обычно сообщения приходят мгновенно. Если Realtime недоступен, приложение само обновляет чат раз в 15 секунд |
